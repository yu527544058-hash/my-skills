# aht-target 使用指南

**一句话**：根据数据定出 AHT 目标，并随着 case 的构成变化灵活调整：长 case 变多了、视频变长了、字数变多了，目标都能跟着重新算。

**顺带**：告诉你处理时间的差异，是 case 本身造成的，还是人造成的。

## 怎么叫出来

- 输入 `/aht-target help`：看这份说明
- 直接说也行，比如："帮我算下 AHT 目标"、"长 case 占比涨到 15% 要给多少时间"、"新项目怎么定标（视频按时长、文本按字数）"

---

## 三种用法，按你的情况选

### 用法一：老项目，长 case 变多了，目标要调多少

**你可以这么说**："长 case 占比从 7% 涨到 12%，AHT 该给多少？"

**必须说清楚的两件事**（最容易出错的地方）：

1. **现在的 AHT 基线是多少，包不包含长 case。** 比如"500 秒是完全没有长 case 时的水平"，还是"500 秒是现在所有 case 的平均"。说反了，答案连加还是减都会反
2. **"长 case"怎么算。** 比如"超过 30 个 segment"。占比和长 case 的平均时长必须用同一个标准

**最好再给我**：长 case 的逐条明细（case ID、segment 数、AHT、标注员）。CSV 最好，截图也行。

**你会拿到**：
- 新的目标值，以及合理区间
- 一个公式：占比每涨 1 个百分点，目标加多少秒
- 数据里的问题：挂机记录、缺失、口径对不上

### 用法二：新项目，按"规模"定标

**先想清楚：这个项目里，什么东西越多，处理就越费时？** 这就是"规模"：

| 项目类型 | 规模是 | 单位 |
|---|---|---|
| 视频类 | 视频时长 | 秒 |
| 文本类 | 文本字数 | 字 |
| 图片类 | 图片张数 | 张 |
| 文档类 | 页数 | 页 |

**原理**：每条处理时间 = 起步时间 + 每单位多花 × 规模

就像打车费 = 起步价 + 每公里的钱。
- **起步时间**：不管多长都要花的（打开、加载、看要求、检查、提交）
- **每单位多花**：规模每多一点要多花的时间。视频就是"每秒多花几秒"，文本就是"每 100 字多花几秒"

举个文本的例子：起步 1 分钟，每 100 字多花 12 秒，那么 500 字的文本要 2 分钟，2000 字的要 5 分钟。

**分三步**：

| 什么时候 | 你给我 | 我给你 |
|---|---|---|
| **定标** | 项目经理试标（最多 30 条）：case ID、规模（视频时长 / 字数…）、AHT、标注顺序；再告诉我正式生产时平均有多长 | 起步时间、每单位多花、基线 AHT |
| **上线 2–3 天后** | 生产的逐条数据（多一列标注员） | 按标注员真实水平的新规律，以及"标注员比项目经理慢/快多少" |
| **以后每一批** | 这批的平均规模（平均时长 / 平均字数…） | 这批的 AHT 目标 |

**列名直接写"视频时长""字数""图片数"就行**，我会自动认出单位。

**试标小贴士**：
- 短、中、长都要挑。最长的至少是最短的 2 倍，否则算不出"每单位多花"
- 前 3–5 条是热身，偏慢，可以不算。不确定的话我会帮你检测
- **上线后那一步不能省**：项目经理一个人的速度，和标注员可能差很多

### 用法三：想知道 AHT 为什么波动这么大

**你可以这么说**："帮我看看这批数据，AHT 差异是什么造成的"

**要给我**：逐条明细，最关键的是**标注员**和 **case ID** 两列。如果同一个 case 被两个人做过，就能直接算出"换个人做差多少倍"。

**你会拿到**：
- 差异里有多少来自 case 本身，多少来自人
- 每个标注员相对同一批 case 的快慢
- 可疑记录（比如一条 case 花了 3 小时）

## 数据格式

- **CSV 最好。** 截图也可以，但别压缩太狠，否则我只能读出汇总行
- **列名中英文都行**：case ID / 视频时长 / 字数 / 图片数 / segment / AHT / 标注员 / 顺序
- **视频时长写秒数或 `mm:ss` 都行；字数写数字就行，带逗号的（1,200）也行**
- **deferred、In check、Not found 不要删，原样留着。** 我会单独检查它们是不是偏向长 case，偏的话目标会被低估

## 常见问题

**算出来的目标能直接考核个人吗？**
不建议。它是排产、估人力用的平均值。同一个 case 换个人做经常差 2 倍，拿平均值考核，会有一半的人不达标。

**数据要多少条才够？**
试标 20–30 条能看出规律。要判断人和人之间差多少，最好有 50 条以上，并且有同一个 case 被多人做过。

**结果为什么总带一个区间？**
样本有限，真实值大概率落在区间里。想留余量就往上取。

**占比涨了，是不是一定要加时间？**
一般是。但如果长 case 本身也变长、变难了，要加的会更多。我会检查这一点。

## 我会主动提醒你的事

- 口径对不上：占比和长 case 平均时长不是按同一个标准算的
- 某一条记录特别离谱，像挂机
- 你要算的情况超出了已有数据的范围，结果只是估算
- 数据太少，结论不可靠
